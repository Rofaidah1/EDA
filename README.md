# Car Prices Data Analysis & Data Cleaning

## Project Overview
This project focuses on exploring, analyzing, and cleaning a car sales dataset using Python. The main goal is to improve data quality by identifying missing values, investigating inconsistent records, and correcting vehicle information to make the dataset more reliable for further analysis.

## Technologies & Libraries
- Python
- Pandas
- NumPy
- Requests
- Jupyter Notebook

## Dataset Description
The dataset contains information about used car sales, including:

- Make and Model
- Year
- Trim
- Body Type
- Transmission
- VIN (Vehicle Identification Number)
- Condition
- Odometer
- Exterior and Interior Colors
- Market Value (MMR)
- Selling Price
- Sale Date

## Project Workflow

### 1. Data Exploration
- Loading and inspecting the dataset.
- Understanding data types and dataset structure.
- Exploring numerical and categorical features.
- Identifying missing values.

### 2. Data Cleaning
- Handling missing values in different columns.
- Standardizing car manufacturers' names.
- Correcting inconsistent vehicle information.
- Converting columns to appropriate data types.
- Investigating missing vehicle details using VIN information.

### 3. Data Analysis
- Exploring car manufacturers and models.
- Analyzing vehicle conditions.
- Investigating transmission types.
- Exploring vehicle years and odometer readings.
- Examining selling prices and other numerical features.

### 4. VIN-Based Data Recovery
- Using VIN prefixes and patterns to investigate missing vehicle information.
- Applying grouping techniques to recover missing values from related records.
- Integrating the NHTSA Vehicle Product Information Catalog (vPIC) API to retrieve vehicle specifications.
